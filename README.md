# BillBot - AI Invoice Generator

A full-stack AI-powered Invoice Generator built with the MERN stack (MongoDB, Express.js, React.js, and Node.js), styled with Tailwind CSS, powered by Google Gemini AI. The application simplifies invoice creation, management, payment follow-ups, and financial tracking through intelligent automation.

## Features

- Secure user authentication with JWT
- Create, edit, delete, and manage invoices
- Generate invoices from plain-text prompts using AI
- Generate AI-powered payment reminder emails
- View AI-generated financial insights on the dashboard
- Manage business profile information
- Download invoices as PDF or print them instantly
- Fully responsive and modern user interface

## Tech Stack

### Frontend
- React.js
- Tailwind CSS

### Backend
- Node.js
- Express.js

### Database
- MongoDB
- Mongoose

### AI
- Google Gemini AI

### Authentication
- JWT (JSON Web Token)
